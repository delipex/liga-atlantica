⚡ Cadastro Automático de Jogadores

Para cadastrar novos jogadores na planilha com apenas um clique a partir do validador, insira a URL do Web App do Google Apps Script configurado na sua planilha:

Ver código do Google Apps Script para colar na planilha 
function doGet(e) {
  var id = e.parameter.id || "";
  var name = e.parameter.name || "";
  var cat = e.parameter.category || "";
  
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("Jogadores");
  if (!sheet) {
    return ContentService.createTextOutput("ERROR: Aba 'Jogadores' não encontrada.").setMimeType(ContentService.MimeType.TEXT);
  }
  
  // Adiciona a linha no final
  sheet.appendRow([id, name, cat]);
  
  // Retorna sucesso com cabeçalhos de CORS habilitados
  return ContentService.createTextOutput("SUCCESS")
    .setMimeType(ContentService.MimeType.TEXT);
}
